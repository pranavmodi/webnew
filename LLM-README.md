# LLM README

This repository is the Possible Minds marketing website at
`https://getpossibleminds.com`.

Before creating, editing, or publishing any blog post, read and follow the
project blog-writing skill:

- [Blog Writer Skill](./skills/blog-writer/SKILL.md)

Use that skill for all future blog posts. It captures the expected editorial
voice, SEO/AEO structure, internal-linking approach, structured-data standards,
technical implementation steps, and live verification workflow.

For normal engineering context, also read [CLAUDE.md](./CLAUDE.md).
